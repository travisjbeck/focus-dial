# Muji Japanese Minimal Theme

## Design Philosophy

This theme embodies the core principles of Japanese minimalism, drawing inspiration from Muji's timeless aesthetic and traditional Japanese design philosophy.

### 間 (Ma) - The Art of Negative Space

Ma is the concept of purposeful emptiness or pause. In this design:
- **Generous whitespace** surrounds all elements
- **Breathing room** between interface components
- **Intentional gaps** that allow the eye to rest
- **Spacious layouts** that never feel cramped

### 侘寂 (Wabi-Sabi) - Beauty in Imperfection

While digital interfaces can appear perfect, we embrace subtle imperfections:
- **Warm, natural tones** that feel lived-in rather than sterile
- **Soft shadows and borders** that mimic natural materials
- **Gentle transitions** that feel organic rather than mechanical

### 簡素 (Kanso) - Simplicity and Elimination

Every element serves a purpose:
- **No decorative buttons** - pure functionality
- **Single accent color** throughout the entire interface
- **Typography as the primary design element**
- **Essential information only**

## Color Philosophy

### Light Mode - Natural Paper
- **Primary Background**: `#FAFAF8` - Warm off-white like quality paper
- **Text Primary**: `#57544F` - Deep charcoal, easy on the eyes
- **Text Secondary**: `#A8A5A0` - Soft gray for supporting information
- **Accent**: `#c2e189` - Muted sage green inspired by traditional pottery

### Dark Mode - AMOLED Pure Black
- **Primary Background**: `#000000` - Pure black for AMOLED efficiency
- **Text Primary**: `#F5F4F0` - Warm off-white maintaining natural feel
- **Accent**: `#c2e189` - Same sage green maintains brand consistency

## Typography Treatment

### Hierarchy Through Weight, Not Size
- **Ultra-light weights** (200) for large time displays
- **Light weights** (300) for body text
- **Regular weights** (400) only for emphasis
- **Minimal letter-spacing** for natural reading rhythm

### Size Relationships
- **Time displays**: 72px-96px - Commanding but not aggressive
- **Body text**: 16px-18px - Comfortable reading size
- **Labels**: 14px - Subtle supporting information

## Interface Elements

### Removed Elements
- All button controls (pause/stop/start)
- Theme toggle switches
- Decorative borders and shadows
- Progress bars (replaced with subtle ring)

### Essential Elements Only
- **Time as primary information**
- **Project names in simple lists**
- **Duration presets as text labels**
- **Minimal progress indication**

## Screen-Specific Design

### Idle Screen
- **Central time display** with maximum breathing room
- **Subtle status text** below
- **No competing elements**

### Project Selection
- **Vertical list** with perfect rhythm
- **Clear selection indication** through color only
- **Consistent spacing** between items

### Timer Running
- **Large countdown** as hero element
- **Minimal progress ring** (single pixel stroke)
- **Small project label** for context

### Duration Selection
- **Prominent time display**
- **Horizontal preset arrangement**
- **Text-only interaction** elements

## Responsive Considerations

The design scales gracefully:
- **Proportional sizing** maintains visual hierarchy
- **Consistent spacing ratios** across screen sizes
- **Typography scales** with container dimensions

## Cultural Inspiration

This theme draws from:
- **Muji's product philosophy** - no-brand quality goods
- **Traditional Japanese tea ceremony** - focus on essential ritual
- **Zen Buddhism** - mindfulness through simplicity
- **Japanese paper crafts** - natural, warm textures

## Implementation Notes

- **No JavaScript interactions** for buttons (none exist)
- **Pure CSS animations** with natural easing
- **CSS custom properties** for consistent theming
- **Automatic theme switching** for demonstration purposes
